Código muerto candidato

Regla (candidato, no veredicto): alcanzabilidad. Se parte de los puntos de entrada: formulario o Sub Main de inicio de cada proyecto EXE; clases expuestas (VB_Exposed=True) y UserControls de proyectos ActiveX DLL/EXE/OCX, con sus miembros Public y los de cualquier UserControl (API expuesta); y los procedimientos citados en AddressOf. Si no se puede determinar el punto de entrada de un proyecto (sin .vbp o con un inicio que no está en el grafo), todo el proyecto se considera vivo. Desde un procedimiento alcanzable se siguen las aristas CALLS, USES_VAR (Get, Let y Set son unidades separadas: leer una propiedad alcanza su Get; asignarla, su Let/Set), OPENS_FORM, INSTANTIATES y CALLS_API resueltas o heurísticas. Usar un miembro de un formulario (frmX.Refrescar, frmX.txt) lo carga, igual que Show/Load/New. Un formulario, clase o UserControl alcanzable hace alcanzables sus manejadores de eventos (HANDLES_EVENT: Form_Load, controles, menús, WithEvents, Class_Initialize), sus métodos Implements y los UserControls que contiene. Las aperturas del propio formulario (Me.Show, Load Me, Me.Visible = True) no lo hacen alcanzable. Conservador: una llamada tardía o sin tipo x.Nombre (x As Object/Form, CallByName(obj, "Nombre")) desde código alcanzable mantiene vivo por enlace tardío (posible) a todo procedimiento no Private llamado Nombre de las clases, formularios y UserControls del proyecto, y a lo que estos alcanzan; lo mismo los candidatos de una variable asignada con varios objetos. Un procedimiento es candidato solo si ningún camino, resuelto o posible, lo alcanza; un formulario está nunca abierto si no es alcanzable, y los procedimientos suyos que algo referencia (o que manejan sus eventos) se listan aparte. Lo declarado dentro de un #If inactivo (según CondComp/#Const) no se compila y se lista aparte. Un acceso tardío a una propiedad sin paréntesis (x = o.Nombre, o.Nombre = v) cuenta igual que una llamada; el uso implícito del miembro por defecto (Attribute X.VB_UserMemId = 0: obj("k"), obj!k, obj = v; -4 para For Each) llega a ese miembro, y sobre un objeto tardío mantiene posibles todos los miembros por defecto del proyecto. CallByName con un nombre calculado mantiene posibles todos los miembros públicos del tipo del objeto (o de todas las clases y formularios si el tipo es desconocido) y deja un aviso callbyname_dynamic. Lo referenciado solo desde código #If inactivo se lista aparte: borrarlo rompe el build si cambia la constante. Archivos compartidos: cada proyecto que compila un archivo tiene sus propios nodos; un candidato es seguro para borrar del archivo fuente solo si está muerto en todos los proyectos que compilan ese archivo, no es posible por enlace tardío en ninguno y todo procedimiento que lo referencia (en cualquier proyecto) también es borrable: VB6 compila todos los procedimientos del archivo. Los que se referencian entre sí forman un grupo de borrado que se borra junto. Una referencia desde código vivo en otro proyecto o desde un #If inactivo lo bloquea. Eval o los clientes externos no se ven: revise antes de borrar.
